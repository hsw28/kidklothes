# kidklothes (Expo MVP)

Cross-platform React Native app (iOS + Android) for saving kids clothing items by URL and building outfits.

## Stack

- Expo + React Native + TypeScript
- React Navigation (tabs + native stacks + deep linking)
- Local persistence with `expo-sqlite`
- Structured so storage logic can be swapped later (e.g. Supabase adapter)

## Setup

```bash
npm install
npm run start
```

Then press `i` for iOS simulator or `a` for Android emulator.

- `kidklothes://items/add?url=<encodedUrl>`

The app deep link config lives in:

### Android (works end-to-end)

1. Install dependencies:

```bash
npm install
```

2. Generate native project and apply config plugin:

```bash
npx expo prebuild
```

3. Run Android dev build:

```bash
npx expo run:android
```

4. In Chrome/Safari (Android), use Share on a product page and pick **kidklothes**.
5. App opens to Add Item with URL prefilled.

Notes:

- Requires a dev build or production build (not Expo Go) because share intents are native.
- Android handling is configured by the `expo-share-intent` plugin in `/Users/Hannah/Programming/kidklothes/app.json`.

Troubleshooting:

- This project pins Gradle to JDK 17 via:
  - `/Users/Hannah/Programming/kidklothes/android/gradle.properties`
  - `org.gradle.java.home=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home`
- If Android build still fails, stop old daemons and retry:
```bash
cd /Users/Hannah/Programming/kidklothes/android
./gradlew --stop
cd /Users/Hannah/Programming/kidklothes
npx expo run:android
```

### iOS (best possible in Expo workflow)

Implemented with `expo-share-intent` plugin and deep-link routing, but requires native build steps:

1. Prebuild native iOS project:

```bash
npx expo prebuild
```

2. Build/run iOS dev client:

```bash
npx expo run:ios
```

3. In Xcode, ensure the Share Extension target generated by plugin is included in your signing/provisioning setup.
4. Share a URL from Safari and choose **kidklothes**; shared URL should route into Add Item.

Notes:

- Expo Go does not support custom share extension targets.
- If team provisioning/capabilities block extension installation, Android flow still works and manual URL entry in Add Item remains available.
